# debugging-app-practice

## 概要

COACHTECH 教材 Tutorial 10-4「デバッグ ハンズオン演習」で作成した成果物です。
デバッグ手法を実際に手を動かして確認します

## 使用技術

- PHP 8.x
- Laravel 10.x
- デバッグツール（`dd()`, `dump()`, `Log` ファサード）

## 学んだこと

- エラーメッセージを読んで問題を理解できる
- dd()でデータを確認してデバッグできる
- Log::info()でログを出力して処理を追跡できる
- Mass Assignmentエラーを修正できる
- ミドルウェアでログを一元管理し、HTTPライフサイクルを可視化できる
